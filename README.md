Médiathèque
Présentation du projet :

Cette application permet de gérer une médiathèque. Elle permet de gérer les clients, les livres et les emprunts.
L'objectif est de faciliter la gestion des ressources de la médiathèque et de suivre les emprunts effectués par les clients.

Fonctionnalités principales :
- Ajouter, modifier et supprimer des clients
- Ajouter, modifier et supprimer des livres
- Consulter la liste des livres disponibles
- Enregistrer un emprunt
- Enregistrer le retour d'un livre
- Consulter les emprunts en cours
- Rechercher un livre
- Consulter les informations d'un client

Utilisateurs
L'application sera principalement utilisée par :
- Les employés de la médiathèque
- Les responsables de la médiathèque

Opération métier principale
L'opération métier principale est l'emprunt d'un livre par un client.
Lorsqu'un client emprunte un livre, l'application enregistre le client, le livre emprunté ainsi que la date de l'emprunt. Le retour du livre pourra également être enregistré.

Principales données gérées
Clients
- Identifiant
- Nom
- Prénom
- Adresse
- Adresse e-mail
- Numéro de téléphone

Livres
- Identifiant
- Titre
- Auteur
- Genre
- Année de publication
- Disponibilité

Emprunts
- Identifiant
- Client
- Livre
- Date d'emprunt
- Date de retour prévue
Date de retour réelle
